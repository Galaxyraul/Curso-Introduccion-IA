BLOQUE 06

Árboles de Decisión

Rompiendo la linealidad con estructuras jerárquicas "White Box" explicables.

Anatomía: El Algoritmo CART

Nodo Raíz

El inicio. Contiene el 100% de los datos. Busca la mejor pregunta para dividir la población.

Nodo Decisión

Puntos intermedios. Evalúan una característica (Ej: ¿Edad > 30?) para bifurcar el camino.

Hoja (Leaf)

Punto final. No se divide más. Contiene la predicción final (Promedio o Moda).

Impureza de Gini

Gini = 1 - Σ (p_i)²

El algoritmo busca reducir la "suciedad" del nodo. Gini=0 significa pureza total (todos son de la misma clase).

El Peligro: Overfitting

Los árboles son camaleones. Si no los limitas, memorizarán cada dato.
Solución: Poda (Pruning) con max_depth.

BLOQUE 07

Ensembles

La sabiduría de las masas: Bagging, Boosting y el estado del arte en datos tabulares.

Paralelo vs Secuencial

Bagging (Paralelo)

Reduce Varianza

Entrena muchos árboles independientes a la vez, cada uno con una visión parcial de los datos.

Random Forest: Democracia. "Si 100 expertos votan, el error individual se cancela".

Boosting (Secuencial)

Reduce Bias

Entrena árboles en cadena. Cada árbol intenta corregir los errores del anterior.

XGBoost / LightGBM: Mejora continua. Se enfoca obsesivamente en los casos difíciles.

Analogía:

Bagging: Un consejo de sabios debatiendo.
Boosting: Un estudiante repasando una y otra vez solo las preguntas que falló en el examen anterior.

BLOQUE 08

No Supervisado

Sin etiquetas, solo estructura. Agrupamiento geométrico y por densidad.

Topología de Datos

K-Means

Minimiza Inercia
  • Necesitas decirle K (nº grupos).
  • Asume formas esféricas (burbujas).
  • Muy rápido, pero sensible a outliers.

DBSCAN

Densidad Conexa
  • No necesita K.
  • Encuentra formas raras (lunas, serpientes).
  • Detecta y excluye el Ruido.

"K-Means corta el pastel con cuchillo recto. DBSCAN sigue la forma del chocolate."

BLOQUE 09 y 10

Ingeniería de Producción

Pipelines, Optimización de Hiperparámetros y Serialización.

El Pipeline: Tubería Robusta

Flujo de Datos Unificado

Raw Data → [ Imputer ] → [ Scaler ] → [ Encoder ] → [ Model ] → Predicción

Prevención de Fugas

El Pipeline asegura que el fit() del escalador solo vea el Train Set, incluso dentro de la Cross-Validation.

Producción

Serializas un solo objeto (.pkl). Al llegar datos nuevos, el pipeline aplica las mismas transformaciones exactas.

Hyperparameter Tuning

Grid Search

Fuerza bruta. Prueba TODAS las combinaciones de una rejilla definida.

Coste Exponencial

Random Search

Prueba combinaciones al azar. Estadísticamente más eficiente para encontrar el óptimo.

Coste Controlado

Bayesian Optimization: La forma "Smart". Aprende de las pruebas anteriores para saber dónde buscar después (como el juego de "frío o caliente").

Bonus: Datos Desbalanceados

El Problema

99% Sanos vs 1% Enfermos. El modelo optimiza Accuracy diciendo siempre "Sano".

SMOTE (Sampling)

Crea datos sintéticos ("falsos positivos plausibles") interpolando entre vecinos.

Class Weights

La solución elegante. Castiga x99 veces más el error en la clase minoritaria.
